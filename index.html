Shorts Bot

Ferramenta interna e de uso pessoal que publica vídeos curtos educativos (YouTube Shorts) sobre curiosidades e ciência no canal do próprio dono.

O que o app faz

O Shorts Bot roda no computador do dono do canal. Uma vez por dia ele:

  1. Escreve um roteiro curto sobre um fato científico verificável, com fonte citada na descrição.
  2. Gera a narração, monta o vídeo vertical com clipes de bancos de imagens livres (Pixabay/Pexels) e legendas.
  3. Envia o vídeo para o canal do próprio dono usando a YouTube Data API v3 (videos.insert).
  4. Lê as estatísticas públicas dos vídeos do próprio canal (visualizações, curtidas) para escolher os próximos temas.

Quem usa

O app é usado apenas pelo dono do canal, para gerenciar o seu próprio canal. Não há usuários externos, não há cadastro e o app não é oferecido ao público.

Uso da API do YouTube

O Shorts Bot usa os YouTube API Services. Ao usar este app você concorda com os Termos de Serviço do YouTube. Os dados são tratados conforme a nossa Política de Privacidade e a Política de Privacidade do Google.
